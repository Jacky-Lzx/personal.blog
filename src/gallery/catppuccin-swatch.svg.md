博客双主题（Mocha / Latte，快捷键 `t` 切换）用的就是这套调色板。这张卡按「中性色 → 强调色」三行排开：

| 行 | 角色 |
| --- | --- |
| 第一行 | base / mantle / crust / surface0 / surface1（背景层次） |
| 第二行 | mauve / red / peach / yellow / green（强调色） |
| 第三行 | teal / sky / blue / lavender / pink（强调色） |

写作时的配色约定：标题用 `mauve`，命令用 `green`，参数用 `sky`，值用 `yellow`，注释用 `overlay0`。
